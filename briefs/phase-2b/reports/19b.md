## What changed and why

**One rule, in `createSearch` (`tools/search.mjs`): a navigational query puts the entry it names first.** An entry
(site or repo; never a page) is named by the query when the query, without spaces and punctuation, equals:
- its name (`radix ui` = "Radix UI", `shadcn ui` / `shadcn/ui` = "shadcn/ui", `daisy ui` = "daisyUI", `untitledui`),
- its domain, with or without the TLD (`tailwindcss.com`, `motion.dev`, `lucide.dev`, `remixicon.com`),
- its GitHub repo name,
- a one-word query plus "ui" (`aceternity` → "Aceternity UI"), or the query minus a trailing generic word
  (`lucide icons` → "Lucide"; ui, icons, library, components, css, illustrations, palette, kit, app, website, site),
- or, only as the whole query, a former name its record states — "formerly X", "previously X", "successor to X",
  "renamed from X" (`framer motion` → Motion, "successor to Framer Motion"; also Origin UI, RetroUI, Freepik in today's
  records).

If nothing matches exactly, a one-letter typo in a name of 6+ letters still matches (`lotiefiles`, `aceternty ui`,
`uiverze`). A matched entry's score is raised to just above the best score of the query (added when it matched no
word at all). Item ranking is untouched; only entries are moved.

**Two guards**, both found on the tuning side (old eval) before the fresh set was scored:
- a query made only of design vocabulary — elements, variants, categories, Turkish aliases and the generic words —
  describes what it wants and names nothing: "icon library" must not put an entry *named* "Icon Library" first
  (without the guard the old eval loses "icon library" 1 → 2, MRR 0.785 → 0.777);
- pages are never navigational: a page named like a product is about it, not it (framer.com's dictionary page
  "Framer Motion"). Synonym concepts stay eligible, because synonym groups hold product names (shadcn, radix).

**Why saturated BM25 could not do it** (report 19): Radix UI's name and domain match scored 9.8 for "radix", repos
repeating "radix" in four fields 10.6, plus the repo prior. A proportional name boost (`nameJ`) helps named queries
but moves descriptive ones (old eval recall 0.933–0.967, descriptive block 0.9); an exact-name rule does not touch a
query that names nothing.

`tools/eval.mjs` scores `tools/eval/judged-queries-19b.json` next to the brief-19 halves, reading grades from both
judge files. Tests (`tools/search.test.mjs`): a query that is a name, a hyphenated name, a domain, a typo or a former
name puts that entry first, and an old name counts only as the whole query; a vocabulary-only query and a page named
like a product are not navigational. The first fails on main; the second passes on main and fails if either guard
is removed (checked).

## Unsure / open

- **Product names that are also design vocabulary are blocked by the guard.** "figma" is a category alias and
  "spline" an element alias in `taxonomy.json`, so the guard reads both as descriptions; figma.com and spline.design
  are not put first (fresh set: figma has no grade-2 hit in the top 5; spline.design is 2nd). The unguarded variants
  score higher on the fresh set (exTop+all 1.000 / 0.919 / 0.904) but lose the old eval's "icon library" and
  "micro interactions" / "framer motion components". I saw this only on the fresh set, after choosing, so I did not
  tune for it. Candidate: let an exact match on a *site's own domain-less name* ("figma" = figma.com) pass the guard
  when the vocabulary word is a single word, judged on a new held-out set.
- **"tabler icons"** matches tablericons.com (graded 1, a third-party site) exactly, and puts it above tabler.io/icons
  (graded 2), which is a page and therefore never navigational. The rule trusts the catalog's names.
- **Several entries can share a name** ("Lucide" site and repo, "Motion" ×3): all of them go first, ordered by their
  normal score. For "motion.dev" the domain match picks only motion.dev.
- **Typos**: one inserted, dropped or changed letter (heroicns, uiverze, lotiefiles, aceternty ui), in names of 6+
  letters, and only when nothing matches exactly; two slips do not match.
- Judging: 7 judges, 3 rounds; agreement between judges was not measured (no hit judged twice).
