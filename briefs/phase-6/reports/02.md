## Open problems

1. **`catalog/search-index.json` was 35.4 MB (> 25 MB).** The largest single contributor was the auto pattern
   `catalog/patterns/v0.app.json` (`/chat/{name}`, 20,000 items of 42,282): v0.app chat sessions, 13 %
   element-tagged. The guesser marked it high because `chat` is a taxonomy element id ("element id/alias as the
   prefix" branch of the confidence rule) — the brief's rule, but the pages are user-generated chat sessions, not
   examples. Resolved in the coordinator review below (skip file + guesser rule); the index is still over budget.
2. **sectionmaster.com keeps 460 of 682 URLs** (222 dropped): `/sections/<company>-<kind>-<n>` only matches when
   `<kind>` is a taxonomy element, so about/other/portfolio/contacts sections produce no item. Accepted by the
   coordinator. The element ids of the remaining pages are 100 % precise, which was the point of the change.
3. **navbar.design has no variants_from.** Its `/type/<kind>` pages render the per-kind list client-side; the HTML
   contains only the same six "latest navbars" links on every kind page (diffed across four pages), which would have
   tagged those six with all seven kinds. The 7 filter pages are cached anyway (`filters/v-*.html`).
4. **Interpretations of the brief that could be read differently** (all recorded here, none silent):
   - `--suggest` "also try the last two segments" is implemented as an extra grouping `…/{name}/{n}` (numeric leaf)
     or `…/{element}/{n}` (middle segment is an element); numeric leaves are never used as `{name}`.
   - A prefix with no literal segment (root-level paths) can never be high confidence, so `/`-level marketing sites
     do not get an auto pattern.
   - Filter-page links, `urls_from` links and the dedupe against `taken` compare **www-insensitively**
     (`normalizeUrl` plus a www-less host): navbar.gallery/footer.design/cta.gallery serve `www.` URLs in the
     sitemap but relative links without it. Without this, no filter link would have matched.
   - Auto patterns always use `granularity: "page"`; the guesser cannot know "example" vs "page".
   - Webflow's `?<hash>_page=N` counts as "`?page=2` style pagination" (navbar.gallery).
   - `variants_from` ids are validated against the pattern's fixed `element`, or against *some* element when the
     template captures `{element}` — the CLI errors out otherwise, the build only warns and ignores the file.
5. 32 auto-list domains have no `sitemap.json` (brief 01 could not fetch them: blocked/empty) — they are in
   `catalog/patterns-review.json` and need a hand pattern or a `skip` file (brief 05).

  aereference.com (After Effects tips), nerdordie.com (Twitch overlays).
- **B — listing/taxonomy templates removed**, status stays `auto`: colorlib.com `/wp/cat/{name}`; threeui.com
  `/browse/tag/{name}`; webinspoo.com `/tag/{name}`, `/section-type/{name}`, `/category/{name}`; horizonx.so
  `/collections/{name}`.
- **C — guesser rules** (`tools/patterns.mjs`): a prefix whose last literal segment is
  `tag|tags|category|categories|cat|collection|collections|topic|topics` is never high confidence, and neither is a
  prefix containing a region locale segment (`^[a-z]{2}-[a-z]{2}$`, e.g. `ko-kr`, `en-us`, on top of `LOCALE`).
  One test each in `tools/patterns.test.mjs`.
