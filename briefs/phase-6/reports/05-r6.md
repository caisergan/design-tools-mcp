## How the five patterns were chosen

- **tremor.so** — docs relaunched under `tremor.so/docs/…` after the Vercel acquisition; the stored `sitemap.json`
  was crawled when the site was one page (`/`; live `/sitemap.xml` has 57 URLs, but re-crawling writes outside the
  files this brief allows). `urls_from: ["/docs/getting-started/installation"]` takes the docs sidebar (40 matching
  links). Templates `/docs/ui/{name}`, `/docs/inputs/{name}`, `/docs/visualizations/{name}`; `/docs/getting-started/*`
  (install steps) and `/docs/utilities/*` (helper functions) stay out. Tagging reads the segment, so `area-chart`,
  `donut-chart` → `chart`, `dialog` → `modal`, `callout` → `alert`, `toggle` → `switch`; `label`, `divider`,
  `barlist`, `category-bar`, `tracker` stay untagged (5 of 40).
- **themefisher.com / uideck.com / wrappixel.com** — template marketplaces. Each `/products/{name}` (themefisher) and
  `/templates/{name}` (uideck, wrappixel) page is one template with a live preview (themefisher embeds it in an
  iframe), the same kind of item as `colorlib.com /wp/template/{name}` that survived the phase-6 coordinator review.
  Their blog/taxonomy/root pages do not match. Element coverage is inherently low: the slugs are template names
  (`adrian-bootstrap`, `awake-agency-framer-template`), so 0–15%.
- **trees.software** — one React file-tree component with 7 demo pages under `/trees-dev/{name}`; kept as
  `granularity: "example"` even though no taxonomy element fits.
