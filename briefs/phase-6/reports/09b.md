## 4. Problems met

1. **Dead host in a sitemap** — `cssloaders.colorion.co/sitemap.xml` names its canonical host
   `css-loaders.colorion.co`, which does not resolve. Exact error (twice):
   `DNSError: Failed to perform, curl: (6) Could not resolve host: css-loaders.colorion.co. See https://curl.se/libcurl/c/libcurl-errors.html first for more details.`
   No other domain produced a fetch error; no time-outs; no Scrapling exceptions.
2. **`challenge: true` false positives** — `www.animationweb.app` (i18n message string
   `"accessDenied":"Access Denied"` inside a JS bundle) and `cssloaders.colorion.co`
   (`/cdn-cgi/challenge-platform/scripts/jsd/main.js`); both pages returned full content and the flags
   disappeared nowhere vs. blocks. The probe's regex is optimised for interstitials, not for bundles.
3. **`stealth` cold start is heavy** — first stealth page 87 s (animationweb), the notion page 189 s;
   warm pages 3.5–8.9 s. One `dynamic` page took 106 s (notion, `network_idle=True`).
4. **Redirect-only domains** — `library.relume.io` → `relume.ai`, `mocku.co` → `mocku.com`,
   `ui.beste.co` → `beste.dev`, `tinte.railly.dev` → `tinte.dev`, `type-scale.com` → `typescale.com`,
   `tailwindtoolbox.com` → `windytoolbox.com`. Only the first three hold mappable content; the pattern
   drafts therefore use `source_domain` (brief 08 option) and need a corpus sitemap for the target
   domain (`catalog/corpus/sites/{beste.dev,mocku.com,www.relume.ai,kit.cuedesign.space}/` do not
   exist yet; fetching them is a sitemaps-step run, out of scope here).
5. **Own helper bug (fixed in the committed script)** — the first `scroll` run died with
   `NameError: name 'out' is not defined` (the robots branch passed the wrong variable); fixed before
   the real run, the recorded numbers come from the fixed script.
6. **Notion pages** — both notion.site sitemaps are byte-identical (`3440 bytes`, 23 `www.notion.so`
   marketing locs), i.e. the workspace pages are invisible to sitemaps; rendering (dynamic + stealth)
   yields no own-domain links, so they stay unmapped.
7. **Query-string shaders (orbkit)** — the sitemap advertises the 33 shaders as
   `/playground?orb=shdr-01…33`; `matchTemplate` ignores the query, so the pattern engine sees one
   page. Mapping them needs either query-aware matching (tool change) or the site's shadcn registry
   (`/r/{name}.json`), not a pattern.
